# Requesting the restricted four-tunnel data

The four-tunnel source images, 1,703 analysis tiles, and expert masks are available from
the corresponding author on reasonable request. They are not public release assets and
are not covered by this repository's CC-BY 4.0 license.

Send requests to the corresponding author, Donggyou Kim ([dgkim2004@kict.re.kr](mailto:dgkim2004@kict.re.kr)), and include:

1. requester name, affiliation, and institutional contact;
2. research purpose and the specific data subset requested;
3. intended analysis and expected outputs;
4. storage, access-control, and retention plan; and
5. whether any onward sharing or derived-data publication is planned.

Applicable data-use conditions will be communicated before transfer. Depending on the
request, they may restrict redistribution, facility re-identification, and use outside the
approved research purpose. A request does not by itself guarantee transfer.

The public repository already provides anonymous cohort structure, row-level derived
results, protocols, and analysis code so that reported statistics can be audited without
access to tunnel pixels.
